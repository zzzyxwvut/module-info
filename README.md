An attempt to apply all Java [module directives](https://docs.oracle.com/javase/specs/jls/se24/html/jls-7.html#jls-7.7) to a single  
[module declaration](https://github.com/zzzyxwvut/module-info/blob/java/24/module_info/src/org.module.info.demo/tests/module-info.peekaboo).

With `JDK 24` and the provided `build.sh` shell script, the  
source files can be compiled, tested, and packaged.
